# Portrait hero studies

Ten original generated metaphysical image studies for the IMD Lab home page. All are 3:4 portraits, 1086 × 1448 pixels. The numbered WebP files preserve the full generated composition without cropping. They are conceptual illustrations, not scientific evidence or photographs of actual lab facilities.

These earlier candidates are retained as alternatives. The current home page follows the subsequent hands-on research direction and uses `dist/assets/research-in-focus.webp`. The home shortcut alignment fix is in `dist/styles.css`.

| No. | Study | Direction |
| --- | --- | --- |
| 01 | Quiet Orbit | A suspended ring and sphere in impossible equilibrium |
| 02 | Folded Horizon | A translucent plane folding into an impossible horizon |
| 03 | Threshold | An incomplete stone portal crossed by a glass plane |
| 04 | Continuum | A flowing sculptural ribbon and negative space |
| 05 | Suspended Matter | Mineral and glass fragments in vertical balance |
| 06 | Interference | Translucent membranes and poetic wave patterns |
| 07 | Inner Light | A dark monolith opening onto an inner light |
| 08 | Parallel Worlds | Two translucent volumes connected by light |
| 09 | Gravity Study | An architectural sculpture that returns into itself |
| 10 | Emergence | A seed-like core, fluid veil and discrete fragments |

Generation: built-in image generation, one independent request per study. The exact prompts are in `prompts.json`.

For the chosen image, copy its WebP file into `dist/assets`, then update Home intro → Background image and Image description. Use a 3:4 image frame, contain the full image, and keep the portrait about 320–360 CSS pixels wide beside the home text on desktop. On mobile, place it beneath the text. The comparison view uses these proportions; it does not change the stored home image.
